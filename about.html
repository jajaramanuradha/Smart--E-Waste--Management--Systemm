About the Project

Technology-based approach for responsible electronic waste management.

Project Objective

The Smart E-Waste Management System helps users register electronic waste, understand whether an item can be reused or repaired, request collection, and learn responsible recycling practices.

Technology Stack

  • Frontend: HTML, CSS, JavaScript
  • Backend: Python Flask
  • Database: SQLite

Future Enhancements

  • Admin login and management
  • Google Maps collection tracking
  • AI-based waste image classification
  • Notifications and email updates
  • Recycling center locator
